# Транслит

Онлайн-транслитератор: печатаете латиницей — сразу получаете кириллицу (и наоборот). Замена [translit.net](https://translit.net) без рекламы, аккаунтов и зависимостей — один `index.html`.

**Демо:** https://kusokmedi.github.io/translit

## Возможности

- **Живой перевод** — результат пересчитывается на каждое нажатие клавиши, вставлять/редактировать текст можно в любом месте
- **Две панели** — слева ввод, справа результат, счётчики символов
- **Обратное направление** — кнопка `⇄` меняет панели местами (кириллица → латиница)
- **Копировать / Очистить** — одна кнопка копирует готовый результат в буфер обмена
- **Таблица транслитерации** — все варианты схемы с картинки translit.net; клик по клетке вставляет символ в текст
- **Тема** — светлая/тёмная, по умолчанию как в системе, выбор запоминается
- **Без зависимостей** — чистые HTML/CSS/JS, работает офлайн

## Использование

Откройте `index.html` в браузере или зайдите на демо-ссылку.

## Таблица транслитерации

| Кириллица | Латиница |
|---|---|
| а б в г д е з и й к л м н о п р с т у ф ц ы | a b v g d e z i j k l m n o p r s t u f c y |
| ж ч ш щ | zh ch sh shh (или `w`) |
| ё | jo, yo, ö |
| э | je, ä |
| ю | ju, yu, ü |
| я | ja, ya, q |
| х | h, x |
| ъ | ##, #, tvz |
| ь | ', mz |

Правила разбора: сначала ищется самая длинная подходящая комбинация (`shh` → `щ`, `sh` → `ш`, `s` → `с`). Регистр переносится: `Shh` → `Щ`, `SHH` → `Щ`, `privet` → `привет`.

## Примеры

```
privet, mir!        → привет, мир!
shhuka               → щука
ob##jom              → объём
ja hochu spatj       → я хочу спать
```
