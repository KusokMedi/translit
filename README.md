# Транслит

Онлайн-транслитератор в одном окне: печатаете латиницей — текст сразу превращается в кириллицу. Замена [translit.net](https://translit.net) без рекламы, аккаунтов и зависимостей.

**Демо:** https://kusokmedi.github.io/translit

## Как это работает

- Одно большое поле ввода — как на translit.net. Печатаете `privet` — в поле появляется `привет`.
- **`Esc`** переключает режим: *кириллица (транслит)* ⇄ *обычный ввод (латиница)*. Текущее состояние видно по цвету (зелёный = транслит, жёлтый = латиница) и по строке над полем.
  - при включении транслита весь текст в поле конвертируется в кириллицу;
  - при выключении ввод идёт как есть — можно писать латиницей или вставлять готовый русский текст.
- Если комбинация ещё не однозначна (`s`, `sh`), она остаётся латиницей и дорешивается следующей буквой (`sh` → `ш`, `shh` → `щ`). По `Enter`, `Tab`, стрелкам или уходу фокуса незавершённая комбинация до-конвертируется.
- Вставка из буфера конвертируется целиком.
- **Копировать** — весь текст в буфер, **Очистить** — сброс.
- **Таблица транслитерации** — все варианты схемы; клик по клетке вставляет букву.
- Тема берётся из системной (светлая/тёмная) и переключается вместе с ней; своего переключателя нет.

## Таблица транслитерации

| Кириллица | Латиница |
|---|---|
| а б в г д е з и й к л м н о п р с т у ф ц ы | a b v g d e z i j k l m n o p r s t u f c y |
| ж ч ш щ | zh ch sh shh (или `w`) |
| ё | jo, yo, ö |
| э | je, ä |
| ю | ju, yu, ü |
| я | ja, ya, q |
| х | h, x |
| ъ | ##, #, tvz |
| ь | ', mz |

Разбор: сначала ищется самая длинная подходящая комбинация. Регистр переносится: `Shh` → `Щ`, `SHH` → `Щ`, `Zhena` → `Жена`.

Варианты `tvz`, `mz`, `##` работают при вставке и конвертации готового текста; при наборе вживую используются `#`, `'` и обычные комбинации.

## Примеры

```
privet, mir!        → привет, мир!
shhuka               → щука
ob#jom               → объём
ja hochu spatj       → я хочу спать
```
