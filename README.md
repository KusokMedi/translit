# Транслит

Онлайн-транслитератор в одном окне: печатаете латиницей — текст сразу превращается в кириллицу. Замена [translit.net](https://translit.net) без рекламы, аккаунтов и зависимостей.

**Демо:** https://kusokmedi.github.io/translit

## Как это работает

- Одно большое поле ввода — как на translit.net. Печатаете `privet` — в поле появляется `привет`.
- **`Esc`** переключает режим: *кириллица (транслит)* ⇄ *обычный ввод (латиница)*. Текущее состояние видно по цвету (зелёный = транслит, жёлтый = латиница) и по строке над полем.
  - при включении транслита весь текст в поле конвертируется в кириллицу;
  - при выключении ввод идёт как есть — можно писать латиницей или вставлять готовый русский текст.
- Буквы появляются сразу кириллицей — латиница в поле не «висит». Комбинации собираются на лету: `s` → `с`, `sh` → `ш`, `shh` → `щ`, `mjz` → `ь`.
- Вставка из буфера конвертируется целиком.
- **`+` — видимый разделитель**: печатается как обычный символ и остаётся в тексте (`1+2`, `2+2`, `1 + 2 = 3`). Если сразу после плюса набрать латинскую букву — плюс исчезает и разбивает комбинацию: `j+ou` → `йоу`, `s+h` → `сх`, `s+h+h` → `схх`, `shh+uka` → `щука`. При вставке из буфера плюсы сохраняются как есть.
- **Копировать** — весь текст в буфер, **Очистить** — сброс.
- **В кириллицу / В латиницу** — перевести весь текст целиком (обратное направление идёт по той же схеме: `щука` → `shhuka`, `объём` → `ob#jom`, регистр слов сохраняется).
- **Найти в Google / Найти в YouTube** — ищет выделенный фрагмент, а если ничего не выделено — весь текст. Пустое поле — кнопки неактивны.
- **Экранная клавиатура** (внизу, по умолчанию свёрнута) — полноценная 60%+, как на ноутбуке: верхний ряд `esc` + `F1`–`F12` + `insert/home/end/delete`, ряд цифр с `-` `=` и `⌫`, `tab`, `caps`, `enter`, два `shift`, `пробел`. Буквы — русские в QWERTY-позициях, в углу клавиши мелко физическая латинская.
- Работают: буквы, цифры, `-` `=` `\` `,` `.` `/` и их сдвинутые варианты `_` `+` `|` `<` `>` `?`, `⌫`, `delete`, `home`/`end`, `enter`, `пробел`, `esc` (переключает режим). При включённом `shift`/`caps` на клавише показывается сдвинутый символ **вместо** основного (`\` → `|`). `ctrl`/`win`/`alt`/`fn`, `F1`–`F12`, `tab`, `insert` — пустые, без подписей.
- `shift` (левый и правый — независимые) — на один символ: подсветился, следующий знак заглавный, погас. `caps` — до повторного нажатия. Клик по клавише не сдвигает страницу.
- Тема берётся из системной (светлая/тёмная) и переключается вместе с ней; своего переключателя нет.
- **Телефон**: раскладка под узкий экран — компактная шапка, кнопки режима и действий во всю ширину, поле ввода тянется на весь экран, «кириллица/латиница» и поиск в сетке 2×2, экранная клавиатура сжимается под ширину экрана целиком (без горизонтальной прокрутки). Клик по экранной клавише не поднимает системную клавиатуру и не сдвигает страницу.

## Клавиатура и таблица

| Кириллица | Со shift | Варианты |
|---|---|---|
| А Б В Г Д Е З И Й К Л М Н О П Р С Т У Ф Ц Ы | A B V G D E Z I J K L M N O P R S T U F C Y | a b v g d e z i j k l m n o p r s t u f c y |
| Ж Ч Ш Щ | Zh Ch Sh Shh | zh ch sh shh, w |
| Ё | Jo | jo, yo, ö, ` |
| Э | Je | je, ä |
| Ю | Ju | ju, yu, ü |
| Я | Ja | ja, ya, q |
| Х | H | h, x |
| Ъ | ## | #, tvz |
| Ь | ' | ', mjz |

Разбор: сначала ищется самая длинная подходящая комбинация. Регистр переносится: `Shh` → `Щ`, `SHH` → `Щ`, `Zhena` → `Жена`.

Варианты `tvz`, `mjz`, `##` работают и при наборе, и при вставке готового текста.

## Примеры

```
privet, mir!        → привет, мир!
shhuka               → щука
ob#jom               → объём
ja hochu spatj       → я хочу спать
j+ou                 → йоу
s+h+h                → схх
1 + 2 = 3            → 1 + 2 = 3
```
